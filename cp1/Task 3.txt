## Root cause
`/usr/local/bin/nightly-report.sh` was copied from `~/nightly-report.sh` on Nov 9 14:20 with Windows CRLF line endings, so the shebang is `#!/bin/bash\r` and the kernel cannot find that interpreter. Proof: files 17 and 18 (`^M$`, `\r\n`), 19 (cannot run even by hand) and 09 (success before 14:20, failure after).

## Fix
```bash
sudo sed -i 's/\r$//' /usr/local/bin/nightly-report.sh
file /usr/local/bin/nightly-report.sh
sudo systemctl reset-failed nightly-report.service
sudo systemctl start nightly-report.service
```
The change is in the file on disk, so it survives a reboot. (Alternative: `sudo apt install dos2unix && sudo dos2unix /usr/local/bin/nightly-report.sh`.)
