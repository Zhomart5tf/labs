## Justification

- Network, Ubuntu: NAT. The guest reaches the internet through the host, and the host reaches the guest by its NAT address (VMnet8), so ssh works. Bridged would also work, but the VM would appear on the office network with its own address and be reachable by other computers, which a test lab does not need. Host-only has no internet.
- Network, Windows: NAT, for the same reason; it only needs the internet.
- Disk, dynamically allocated: it uses only the space really written, so the host keeps free space. Fixed disk is slightly faster but takes the full size at once, which this computer cannot afford.
- Ubuntu 1 vCPU / 2 GB / 20 GB: Ubuntu Server needs little; this is above its minimum (1 GB RAM, 5 GB disk).
- Windows 11 2 vCPU / 4 GB / 64 GB: this is exactly the Windows 11 minimum (2 cores, 4 GB RAM, 64 GB disk). Nothing is set below a minimum.
- 2 threads and 4 GB are kept for the host so it stays usable.
